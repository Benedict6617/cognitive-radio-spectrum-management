# API Reference (summary)

Full interactive docs are auto-generated by FastAPI at `/docs` (Swagger UI)
and `/redoc` once the service is running.

| Method | Path                              | Description                                              |
|--------|-------------------------------------|------------------------------------------------------------|
| GET    | `/health`                            | Service health check                                        |
| GET    | `/nodes`                             | List registered distributed sensing nodes                   |
| GET    | `/spectrum/latest-fusion`            | Cooperative-sensing fusion result for the latest scan       |
| GET    | `/allocation/best-channel`           | Best available (protected + occupancy aware) channel         |
| GET    | `/allocation/report`                 | Full per-channel allocation status report                    |
| GET    | `/power-control/simulate`            | Run an illustrative power-control convergence simulation     |
| GET    | `/forecast/channel/{channel_index}`  | Attention-based occupancy forecast for one channel            |
